# Feature Overview

## What This Product Can Do

Each row links to a focused guide for that capability.

| Feature | Description | Guide |
|---|---|---|
| Session Recording | Capture supported or explicitly configured LLM and API requests, redact recognized credentials, and record available token/cost data. | [Session Recording](./session_recording.md) |
| Replay Testing | Run your integration tests completely offline and deterministically using recorded local JSON fixtures with zero API costs. | [Replay Testing](./replay_testing.md) |
| Web Visualizer | Inspect your agent runs, timelines, token counts, latencies, and costs side-by-side inside the embedded React dashboard. | [Web Visualizer](./web_visualizer.md) |
| MCP Server | Enable IDE-based AI assistants (like Claude, Cursor, and Copilot) to query and analyze your telemetry database using natural language. | [MCP Server](./mcp_server.md) |
| Cloud Deployments | Deploy the Orchid proxy to any cloud provider with a single copy-paste cloud-init snippet for shared team or staging environments. | [Cloud Deployments](../deployments/README.md) |
